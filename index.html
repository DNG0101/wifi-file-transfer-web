Connection help & privacy
Both devices must use this website; it does not connect to the Android APK. Keep both tabs awake and the room creator online. If connection fails, disable VPNs and avoid guest Wi-Fi or access-point isolation. This version has no TURN relay, so networks blocking direct WebRTC may not work.
PeerJS Cloud brokers connections and sees connection metadata, including peer IDs and network addresses. File contents use a direct encrypted connection. Room membership and device names are shared with browsers in that room. Device names are self-declared: confirm the sender before accepting.
Room pairing requires internet. The original manual pairing version remains available for troubleshooting.
